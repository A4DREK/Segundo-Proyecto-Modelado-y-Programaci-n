    \textbf{Resumen}\\

Este reporte presenta el desarrollo de un sistema de reproducción de música con una base relacional de datos SQLite, utilizando los lenguajes de Rust y Flutter, que para operar en conjunto se utilizó la herramienta de Flutter\_Rust\_Bridge, para poder integrar ambos lenguajes, se implementaron los patrones de DAO y MVC para el correcto desglose de responsabilidades del programa, además de poder desarrollar la aplicación para los sistemas operativos de macOS y Linux.
Se llegó a un sistema que cumple con los requerimientos del proyecto, es decir, procesar archivos ID3V2.4, tener una base de datos la cual almacene los datos de las canciones (Performer, Nombre, Grupo, etc), una interfaz gráfica la cual es capaz de poder reproducir los audios, y una barra de búsqueda.
